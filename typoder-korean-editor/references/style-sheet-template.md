# 작가 노트(스타일 시트) 템플릿

의뢰서에서 받은 답과 작업하며 정한 것을 적는 기록이다. 같은 필자·작품의 다음 작업에서 같은 것을 다시 묻지 않고, 앞에서 정한 표기와 설정을 뒤에서 뒤집지 않기 위해 쓴다. 긴 문서(대략 원고지 30매·A4 5쪽 이상), 여러 번 나눠 작업하는 원고, 연재, 여러 사람이 쓴 원고에서는 **처음에 만들고 작업하면서 채운다.** 짧은 한 번짜리 작업은 '의뢰서'만 작업 메모에 적어도 된다. 편집 보고서에 요약을 붙이고, 확정한 이름·용어는 `fidelity_check.py facts --terms`와 파일 편집 목록의 `terms`에 넘긴다. 글자 그대로 지켜야 하는 실제 인용·승인 문구는 `--protected-text`와 파일 편집 목록의 `protected_text`에 넘긴다.

규칙: 원문·재료에서 확인한 것과 작가가 답한 것만 적는다. 짐작은 '확인 필요'에, 각색에서 새로 정한 것은 '새로 정한 것'에 둔다. 새 결정을 내리면 '결정한 원칙'에 이유와 함께 적고, 이미 편집한 앞부분에도 같은 기준을 적용했는지 확인한다.

```markdown
# 작가 노트: [문서·작품 제목]

## 의뢰서 (확인 / 짐작+근거 / 모름 → 받은 답)
- 역할: (윤색 / 대필 / 각색 / 검토만) · 작업 종류: (맞춤법만 / 다듬기 / AI 티 빼기 / 메모·시놉시스로 쓰기 / 매체 바꾸기)
- 누가 썼나: (사람 / AI / 섞임) · 단계·고칠 폭: (메모 / 초안 / 완성본, 작가가 말한 폭)
- 필자·화자: (누구, 어떤 자리) · 말투 샘플: (있음: 위치 / 없음)
- 독자·용도: (제출처·게시처·받는 사람)
- 분량·형식: (원고지 N매 / N자 / 회차 / 시나리오 형식)
- 지킬 것: (뼈대·결말·말투·손대지 말 곳)
- 바꿔도 되는 것: (각색: 장면 합치기·순서·인물 줄이기)
- 받은 답·정한 것: (날짜와 함께)

## 새로 정한 것 (각색)
| 무엇 | 정한 내용 | 다른 선택지 | 작가 확인 |
|---|---|---|---|
| 결말 방향 | | | 미확인 |

## 문서 정보
- 장르·매체: (보고서 / 블로그 / 소설 / 시나리오 / 이메일 …)
- 독자: (사내 임원 / 일반 독자 / 청소년 …)
- 장르(`--genre`): (보고서 / 블로그 / 웹소설 …)
- 기준 규범: 국립국어원 한글 맞춤법·표준어 규정·외래어 표기법 (지정 스타일 가이드: 있음/없음)

## 고유명사·이름
| 표기 | 종류 | 첫 등장 | 비고(금지 변형) |
|---|---|---|---|
| 김지현 | 인물(팀장) | 2문단 | '김 팀장'으로도 부름. '김지연' 아님 |

## 날짜·시간 표기
- 예: 2026년 3월 5일 / 2026. 3. 5. / 오후 3시 (원문 방식: )

## 숫자·단위 표기
- 예: 1,200명 / 1천2백 명, 40% / 40퍼센트, 3~5 / 3-5 (원문 방식: )

## 용어
| 채택 표기 | 뜻·맥락 | 쓰지 않는 변형 | 근거 |
|---|---|---|---|
| 피처 | ML 입력 특성 | 특징, 기능 | 원문 정의(4문단) |

## 외래어 표기
| 채택 | 비표준 변형 | 처리 |
|---|---|---|
| 콘텐츠 | 컨텐츠 | 통일 / 상표면 공식 표기 유지 |

## 문체
- 종결: 합니다체 / 해요체 / 한다체 (허용하는 섞임: 질문·청유의 해요체 등)
- 인칭·호칭: 저·저희 / 우리 / 필자, 독자 호칭(여러분 / 생략)
- 존댓말·반말: 대사 인물별 (소설)
- 띄어쓰기 방침: 보조 용언 (띄움 / 붙임), 숫자+단위 (붙임 / 띄움)

## 문체 특징 (지킬 것)
- 문장 길이·리듬: 
- 말버릇·사투리·구어: 
- 의도적 반복·수사 의문문: 

## 선호 표현 / 금지 표현
- 선호: 
- 금지(작성자·기관 지정): 

## 유지할 표현 (고치지 않음)
- 보호 구역(실제 인용·슬로건·승인 문구·제목):
- 인물별 말투·말버릇·사투리·높임 관계(대사를 고칠 때 지킬 것): 

## 결정한 원칙
1. (예) '~에 대한'은 대상을 가리킬 때만 남기고 연결 사슬이면 푼다. (근거: 5문단 처리)

## 반복 문제 (자주 나온 오류와 처리)
| 문제 | 종류 | 횟수 | 처리 |
|---|---|---|---|
| 되어지다 | 이중 피동 | 4 | 되다로 통일 |

## 확인 필요 (작성자에게 물을 것)
1.
```
