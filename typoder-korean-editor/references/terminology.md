# 분야 용어 고르기

보고서·논문·기술 문서처럼 분야 용어가 많은 글을 편집할 때 읽는다.

고르는 순서: 사용자 용어집·지정 스타일 → 원문이 정의해 일관되게 쓰는 용어 → 규제 기관·표준·공식 문서 → 독자층의 실무 관행 → 안정된 한국어가 없으면 원어. 맞고 일관된 용어는 영어든 한국어든 다양성을 위해 바꾸지 않는다. 공식 표기나 분야 용례를 확인하지 못하면 추측해 바꾸지 말고 원문을 유지하며 필요하면 `확인 필요`로 남긴다.

| 영어 | 맥락별 한국어 |
|---|---|
| release | 소프트웨어: 출시·배포 / 음반: 발매 / 언론: 보도자료(press release) |
| trial | 의약: 임상 시험 / 법률: 재판 / 서비스: 체험판 |
| margin | 재무: 이익률·마진 / 편집: 여백 |
| issue | 소프트웨어: 이슈·문제 / 금융: 발행 / 잡지: 호 |
| subject | 연구: 연구대상자 / 이메일: 제목 / 문법: 주어 |
| yield | 금융: 수익률 / 제조: 수율 / 농업: 수확량 |
| session | 웹: 세션 / 교육: 차시 / 의회: 회기 |

지킬 것: 코드, 모델명, 제품명, API 필드, 경로, 명령어, 표준 번호, 인용 키는 번역하지 않는다. 용어를 바꾸면서 주장을 세게 만들지 않는다(시제품→출시, 예비 결과→입증, 지침→규정, 연관→원인). `한국어(English)` 병기는 첫 언급에서 독자에게 도움이 될 때만 한다. 확인할 곳: 국립국어원 어문 규범(korean.go.kr/kornorms), 표준국어대사전(stdict.korean.go.kr), 우리말샘(opendict.korean.go.kr), TTA 정보통신용어사전(terms.tta.or.kr), 국가법령정보센터(law.go.kr).
